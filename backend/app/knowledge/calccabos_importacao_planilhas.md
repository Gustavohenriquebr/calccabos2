# Importação de planilhas

O importador deve priorizar tabelas limpas.
Planilhas industriais com cabeçalhos mesclados, BUSBAR, SUBTOTAL e TOTAL podem exigir pré-tratamento.

Campos úteis:
- TAG;
- descrição;
- FROM;
- TO;
- tensão;
- potência kW;
- kVA;
- FP;
- eficiência;
- comprimento/distância;
- proteção/dispositivo.

Ao orientar o usuário, recomende usar uma aba limpa para importação e uma aba visual para documentação.
